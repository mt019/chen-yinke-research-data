# 來源政策

本專案目前以使用者持有的合併七冊 EPUB 作為研究材料。EPUB 原檔、本機路徑與未整理圖片不進 Canvas；由資料倉產生的原文段落可以進入公開資料與前端。

可公開內容限於：

- 書名、作者、卷冊結構與篇名等書目資料；
- 帶有卷章、順序與來源定位的原文；
- 已逐條人工覆核、明標陳述者／撰寫者／轉述性質／原文依據的研究摘要、
  分類、索引與統計；
- 來源狀態、核對狀態與方法說明。

前端顯示原文時，不得丟失卷冊、章次、段落順序與來源定位；前端不得自行解析 EPUB。

機器產生或尚未逐條審核的內容預設只能留在 `editorialDrafts`。使用者
明確允許公開編者解釋時，可逐筆移入 `publicAnnotations`，但必須採用
`draft-disclosed`，並在畫面顯示「編者分段／說明／解讀」。擁有
`basis` 不等於該句話就是原作者原話；未逐條核准者不得標成陳氏論旨。
