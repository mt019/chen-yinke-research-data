# 陳寅恪研究資料

本倉庫是 Canvas Lab「陳寅恪文集研究室」的資料真相來源，保存卷冊目錄、研究筆記、材料狀態與可公開的前端資料。

原始 EPUB 檔留在本機書庫，不納入版本控制。由資料倉整理出的原文、書目、目錄與研究內容可以同步至 Canvas Lab；前端仍不直接讀取 EPUB 或本機路徑。

## 留痕規則

- 研究留痕：`notes/研究紀錄.md`，記來源所見、編者判斷、校勘發現與待核問題。
- 工程留痕：`engineering/LOG.md`，記抽取器、資料模型、驗證、同步與前端變更。
- 研究紀錄須能定位至來源章節、頁碼或區塊 ID；工程紀錄須指出可重做的命令或產物。
- 原始書檔與本機絕對路徑不進版本控制；必要的來源識別資訊以不暴露本機配置的方式記錄。

## 使用

```sh
npm run validate
npm run sync
```

同步後，在 `../my-canvas-lab` 執行 `npm run build`。
